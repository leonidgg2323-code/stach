# STACH — Smart Eyes (Stage 4 upgraded)

A minimal, eye-only companion for the **Waveshare ESP32-S3 Touch AMOLED 1.43-inch (466×466)**. Based on your example photo, with neutral eyes level and equal-sized, no glow or highlights, and eyebrows appearing **only** during a non-neutral emotion. **No surprised emotion.**

## Downloads / preview

- `preview/stach-smart-eyes.mp4` — smooth 18 FPS preview generated **from the same C++ pixel renderer** used for the firmware. 0–8 s gaze movement, 8–10 s angry demo, 10–12 s sleepy demo, 12–16 s happy charging demo. Demonstrations, not recordings of the board.
- `preview/stach-smart-eyes.gif` — compact 12 FPS preview.
- `preview/stach-live-preview.html` — **interactive standalone preview**. Double-click it in your Windows browser. Buttons simulate a fall, low battery, charging and touch; no board or server required. This browser preview has antialiased browser shapes and is approximate; the MP4 and GIF are generated by the actual C++ face renderer.
- `preview/neutral.png`, `preview/look-left.png`, `preview/look-right.png`, `preview/charging.png` — image stills from firmware preview.

## Behavior in code

- **Neutral**: same-size, level white eyes with centered black pupils; no eyebrows.
- **Looking left**: whole pair moves left; **left eye shrinks 17%**, right eye grows 17%, pupils look left.
- **Looking right**: whole pair moves right; **right eye shrinks 17%**, left eye grows 17%, pupils look right.
- **Anticipation**: an intentional brief movement opposite to a glance, before looking left or right. Neutral motion never changes emotional state on its own.
- **Anti-aliasing**: shapes are filled with solid white / black; only boundary pixels use grey RGB565 coverage for smooth edges. No neon, bloom, lens flares or reflections in the eyes.
- **Sleepy**: low battery (below 13%, **only when an independently calibrated battery percentage is available**) or 48 hours without charging **within the same uninterrupted boot**.
- **Angry**: brief freefall followed by impact, detected by accelerometer-magnitude event logic, remains for 6.5 seconds. Simple QMI8658 I2C readout is integrated in the Waveshare firmware profile, but thresholds need real-world calibration. Avoid dropping or throwing your hardware to test.
- **Happy**: charging reported by a real charging-status provider; a thin, flat green charging sweep and battery icon appear. The board's charging-status source has **not been verified**, so charging auto-detection is **not wired up** on real hardware yet. The standalone HTML and generated MP4/GIF simulate this event.
- **Curious**: triggered by touch events through `behavior.touch`; physical touch driver integration is scheduled for a later stage.
- Emotion choice precedence: fall > charging > low battery / elapsed time > touch > neutral. Manual POST `/api/expression?value=...` temporarily overrides the automatic state for 8 seconds to allow checking expressions.

## Files

- `include/stach_face.h`: actual 466x466 RGB565 antialiased renderer and gaze anticipation, charging indicator.
- `include/stach_character.h`: smooth interruption-safe expression transitions.
- `include/stach_behavior.h`: event-driven emotions, fall detection, charge/battery input interfaces.
- `include/stach_imu.h`: minimal Waveshare QMI8658 accelerometer access, active only on Waveshare build profiles.
- `src/main.cpp`: existing Wi-Fi AP and emotion API, integrated renderer and IMU fall events.
- `test/*`: portable host C++ logic tests (including updated smart behavior tests).
- `tools/render_preview.cpp`: C++ pixel-engine frame renderer for preview regeneration.
- `.github/workflows/check.yml`: portable tests + PlatformIO CI build definitions.

## How to use

1. Open `preview/stach-live-preview.html` from the archive to test the visuals without hardware.
2. To upload the project: extract **contents** of the ZIP into your cloned `stach` repository root, replacing existing files, then use GitHub Desktop **Commit → Push origin**.
3. On Linux/macOS or WSL with `g++`, run `sh tools/test_core.sh` to verify portable logic.
4. On a configured PlatformIO computer or GitHub Actions, run `pio run -e stach-network-prototype`, or the matching Waveshare panel profile. **Use a panel profile compatible with your exact board revision.**

## Verification and limitations

Portable C++ tests are included and run on the host. JavaScript in the standalone preview has been syntax checked with Node. The MP4 / GIF were generated using the bundled C++ face renderer. **No complete PlatformIO firmware build or physical Waveshare AMOLED/charger/touch calibration was performed for this version.** A working charging-detect source and battery calibration cannot be guessed from the raw BAT_ADC reading; this needs board validation. Sensor-based fall thresholds can produce false detections and must be calibrated without deliberately dropping the device.
