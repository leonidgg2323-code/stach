# STACH Stage 12 — что на самом деле проверено

Дата подготовки: 21 ноября 2026.

## Подтверждено на текущем шаге

- Фактическая последняя успешная опубликованная сборка **Stage 11**: [GitHub Actions run 44074799310](https://github.com/leonidgg2323-code/stach/actions/runs/44074799310), commit `32767ec22b60993b8aab2436e427768c4a436b9d`. Обе jobs `core` и `firmware` успешны, включая три профиля Stage11. В старом запуске нет сохранённых build artifacts.
- Выполнены повторно переносимые тесты C++ из `tools/test_core.sh`, проверки JS/API, security integration и 8 тестов BLE-патча — все прошли.
- **5 дополнительных тестов** Stage12: формирование SHA256-манифеста, наличие трёх профилей, отказ при пропавшем/пустом `.bin`, запрет 1.43C, правильный размер Flash у аппаратных профилей — пройдены.
- Конфигурация GitHub Actions проверена YAML-парсером: упаковщик артефактов и `actions/upload-artifact@v4` присутствуют.
- Сборщик релизного набора испытан с **фиктивными тестовыми данными исключительно во временных каталогах**. Эти данные **не вложены** в ZIP, не являются настоящими `.bin` и не выдаются за готовую прошивку.

## Не подтверждено

- **Новая** сборка Stage12 в реальном PlatformIO (в этой среде отсутствует PlatformIO и нет доступа к пакетам ESP32). Будет проверена GitHub Actions после коммита и push.
- Скачиваемые `.bin` этой версии появятся только после успешной Stage12 GitHub Actions — в этом ZIP их нет.
- Физическая совместимость с конкретной моделью, запуск экрана, свайпы, падение, батарея, зарядка, сопряжение BLE, стабильность работы 24 часа — только после проверки на реальном Waveshare.

## Критерии для статуса «Этап 12 завершён»

1. Зелёные Stage12 `core` и `firmware` после push + скачиваемый полный артефакт трёх профилей с SHA256.
2. Определена точная аппаратная ревизия (1.43/1.43-B; **не 1.43C**).
3. Успешная загрузка на плату и проход всех применимых тестов из `STAGE12-HARDWARE-TESTS.md` без неподтверждённых функций.
4. Измерены и калиброваны батарея и зарядка либо эти неподтверждённые возможности явно отключены/помечены.
5. После тестов можно подготовить финальный тег `v1.0.0`. Пока лишь `12.0.0-rc1`.
