# STACH — аппаратная самодиагностика (возврат к этапу 2)

## Что добавлено

- Аппаратный отчёт на **момент загрузки** для стандартной Waveshare 1.43 / совместимой B: фактически обнаруженные 16 МБ Flash, PSRAM, I²C, сенсор, гироскоп, RTC и результат `display::begin()`.
- Отличает **I²C-ACK** (устройство ответило по адресу) от успешной инициализации драйвера. Ни то ни другое не доказывает, что экран и сенсор полностью исправны.
- Диагностический HTTP-адрес `GET http://192.168.4.1/api/hardware` через существующий `guardRequest(false)`; не показывает пароль сети и BLE-ключи.
- В USB Serial Monitor появляется запись `[HWSELFTEST]`, в которой `warnings` — битовая маска. `basicDriversReady` — диагностический сигнал, **не аппаратная приёмка**.
- USB-команда `D` показывает **на 5 секунд** белую тестовую графику и три цветные полосы AMOLED. `I` повторяет стартовую диагностику. Не включать Mouse Mode для проверки экрана.

## Как проверять на физическом устройстве

1. Проверь точную маркировку: это **не 1.43C**. Она несовместима с текущей распиновкой, даже если у неё такой же диагонали дисплей.
2. Подключи стандартную 1.43 / совместимую B USB-кабелем с передачей данных. Для текущих драйверов выбери **подтверждённый** профиль `stach-waveshare-sh8601` или `stach-waveshare-co5300`.
3. Залей прошивку через PlatformIO и открой `pio device monitor -p COM5 -b 115200` (замени COM5). Если D не отправляется, включи отправку символов в терминале или используй другой Serial Monitor.
4. Проверь запись `[HWSELFTEST]`: объём Flash ~16777216, PSRAM ~8388608 байт, `display=1`, `imu=1`, `touch=1`. Несовпадение необходимо исследовать по документации именно твоей ревизии.
5. Подключись к Wi-Fi Stach и открой `http://192.168.4.1/api/hardware`. API показывает стартовый снимок, а не постоянно обновляемые измерения.
6. Отправь `D` через Serial Monitor: проверь наличие круга, белых глаз, красной/зелёной/синей полос. Через 5 секунд Stach вернётся к обычным глазам. Если в Serial `display=1`, а изображение неверно — ищи аппаратную несовместимость/неправильную ревизию/инициализацию контроллера.
7. Проверь касание, наклон, Bluetooth и зарядку по отдельному чек-листу `STAGE12-HARDWARE-TESTS.md`. Не бросай плату и не делай тестов с оголённым аккумулятором.

## Биты `warningMask`

| Бит | Значение |
|---|---|
| 0x001 | Несовпадение объёма Flash (ожидание 16 МБ) |
| 0x002 | PSRAM отсутствует или менее 7 МБ |
| 0x004 | Нет I²C |
| 0x008 | Нет ответа сенсора по I²C |
| 0x010 | Нет ответа IMU по I²C |
| 0x020 | Нет ответа RTC (предупреждение, но не блокирующая ошибка) |
| 0x040 | AMOLED `begin()` не прошёл |
| 0x080 | Драйвер сенсора не инициализировался |
| 0x100 | Драйвер IMU не инициализировался |

**Границы реализации:** драйвер SH8601/CO5300 компилировался ранее, но его реальная работа на конкретной Waveshare не проверена. Устройства FT3168/FT6146 и QMI8658 проверяются в коде, но калибровка, работоспособность сенсора, IMU и заряда требуют физического устройства. `hardwareValidated` всегда `false` до ручной аппаратной приёмки; самодиагностика его не меняет.
