STACH перетворює **Waveshare ESP32-S3-Touch-AMOLED-1.75** на кишенькового компаньйона. Його очі стежать за вашим пальцем і реагують на нахил. Проведіть пальцем праворуч, щоб грати в ігри, або скористайтеся телефоном, щоб змінити його вираз, яскравість, поведінку та назву дисплея. Плата містить власну мережу Wi-Fi і панель керування.

## Встановити на Waveshare 1.75

Ці інструкції було перевірено на Windows із середовищем `stach-eyes-175` PlatformIO. Він створює повну програму з `src/main.cpp` для круглого дисплея 466 × 466 CO5300, 16 МБ флеш-пам’яті та 8 МБ PSRAM. Перед перепрошивкою перевірте модель на платі або її упаковці. Версії 1.43, 1.43B і 1.75C мають інше апаратне забезпечення.

### 1. Підготуйте комп’ютер

Для першої збірки вам потрібен Python 3.13 із засобом запуску `py`, Git для Windows, USB-кабель даних і підключення до Інтернету. [Python для Windows](https://www.python.org/downloads/windows/) · [Git для Windows](https://git-scm.com/downloads/win)

Відкрийте PowerShell і клонуйте проект у нову папку. Короткий шлях із символами ASCII добре працює з інструментами ESP32.

```powershell
cd $env:USERPROFILE
git clone https://github.com/leonidgg2323-code/stach.git stach-firmware
cd stach-firmware
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "platformio==6.2.0"
```

Або виберіть **Code → Download ZIP** на GitHub і розпакуйте архів. Відкрийте PowerShell у папці, що містить `platformio.ini`, і виконайте дві останні команди вище. Наведені нижче команди безпосередньо викликають Python віртуального середовища.

### 2. Встановіть залежності та побудуйте

```powershell
.\.venv\Scripts\python.exe -m platformio pkg install -e stach-eyes-175
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175
```

Перша збірка завантажує інструментарій ESP32 і може зайняти кілька хвилин. Збірка автоматично застосовує виправлення сумісності бібліотеки миші Bluetooth. Зачекайте на `stach-eyes-175  SUCCESS` перед завантаженням.

### 3. Знайдіть послідовний порт і прошити плату

Підключіть плату через USB і перелічіть доступні порти.

```powershell
.\.venv\Scripts\python.exe -m platformio device list
```

Визначте порт, який з’являється, коли ви під’єднуєте плату, і зникає, коли ви її від’єднуєте. Замініть `COM3` у прикладах на свій порт. Закрийте будь-яку програму, яка його використовує, включаючи монітор послідовного порту Arduino IDE.

**Завантаження замінює прошивку на платі.** Щоб зберегти можливість відновлення заводського меню, збережіть повну резервну копію флеш-пам’яті за межами сховища перед завантаженням. Повна резервна копія для цієї моделі – **16,777,216 bytes**. Використовуйте нову назву файлу, якщо у вас уже є резервна копія. Зображення може містити налаштування та облікові дані, тому зберігайте його приватним.

```powershell
.\.venv\Scripts\python.exe -m pip install "esptool>=5,<6"
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 read-flash 0 ALL "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

Щоб інсталювати STACH, виконайте команду upload.

```powershell
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175 -t upload --upload-port COM3
```

Плата перезавантажується після перевірки контрольної суми та повідомлення `SUCCESS`. PlatformIO записує завантажувач, таблицю розділів і програму за відповідними адресами. Файл `firmware.bin` у каталозі збірки містить лише програму.

### 4. Зареєструйте обліковий запис власника

1. Під час першого завантаження скануйте **1/2 JOIN WI-FI** телефоном. Приєднуйтесь до мережі `Stach-XXXXXX`. Якщо ваш телефон повідомляє, що він не має доступу до Інтернету, виберіть **Залишайтеся на зв’язку**.
2. Дисплей перемикається на **2/2 REGISTER**, коли телефон підключається. Якщо перший код все ще відображається, торкніться дисплея один раз. Відскануйте другий код за допомогою того самого телефону.
3. Виберіть ім’я користувача з 3–32 літер (A–Z або a–z), цифр, дефісів або підкреслень, а також пароль із принаймні 12 символів. Збережіть дані для входу. Обліковий запис і налаштування зберігаються на дошці.
4. В **Аккаунт владельца** (обліковий запис власника) ви можете змінити ім’я, яке відображається на панелі, або вийти. Для подальших відвідувань підключіться до Wi-Fi дошки та відкрийте [локальна панель керування STACH](http://192.168.4.1/).

Дошка приймає один обліковий запис власника. Для реєстрації потрібен одноразовий код, який відображається на фізичному дисплеї. Для команд керування потрібен сеанс власника та маркер запиту. Панель використовує HTTP у локальній мережі Wi-Fi плати. Увійдіть знову після перезапуску дошки.

## Жести та ігри

| Дія | Результат |
|---|---|
| Торкніться очей або нахиліть дошку | Очі стежать за пальцем або за нахилом. |
| Проведіть праворуч від очей | Відкрийте меню ігор. |
| Проведіть пальцем ліворуч у грі | Повернення до меню. Знову проведіть ліворуч, щоб повернутися до очей. |
| Утримуйте екран очей приблизно секунду | Показати QR-код Wi-Fi. Торкніться, щоб переключитися між кодами мережі та панелі. Утримуйте, щоб повернутися до очей. |
| Проведіть вгору від очей | Запустіть режим миші Bluetooth. Підключіться до **Stach Mouse** на вашому комп’ютері та тримайте плату нерухомо для калібрування. |
| Торкніться екрана в режимі миші | Торкніться, щоб клацнути лівою кнопкою миші, двічі торкніться, щоб клацнути правою кнопкою миші, проведіть пальцем, щоб прокрутити, або утримуйте, щоб вийти. |

У **Targets** вразіть якомога більше цілей за 20 секунд. У **Sums** дайте відповідь на п’ять додаткових запитань. Обидві ігри показують ваш рахунок і зберігають ваш особистий рекорд. **Dice** кидає шестигранний кубик, а **Coin** кидає монету. Кожен результат надходить від апаратного генератора випадкових чисел ESP32. Натисніть ще раз після завершення анімації для нового кидка або перевороту.

## Дисплей і живлення

Панель телефону включає в себе вибір виразу обличчя, джойстик погляду, керування морганням і нахилом, яскравість очей і налаштування того, наскільки очі рухаються самостійно. Налаштування зовнішнього вигляду зберігаються під час перезапусків. Ви можете ввімкнути режим миші після запуску.

На платі 1.75 **AXP2101** повідомляє відсоток батареї та стан зарядки. Індикатор показує `USB`, коли плата працює від кабелю та не виявляє батареї. Якщо ввімкнено енергозбереження, частота оновлення очей падає після 45 секунд бездіяльності, а екран вимикається через 5 хвилин. За заявленого заряду 15% або менше ці інтервали зменшуються до 10 секунд і 2 хвилин. Торкніться екрана, щоб розбудити його. Ігри, QR-коди, режим миші та активна зарядка не дозволяють дисплею спати.

## Усунення несправностей і відновлення

| Симптом | Що спробувати |
|---|---|
| Новий COM-порт не відображається | Спробуйте USB-кабель даних та інший USB-порт, а потім знову запустіть `platformio device list`. |
| Порт не відкривається або повідомляє `Access denied` | Закрийте серійний монітор. Повторно підключіть плату та перевірте її номер COM. |
| Збірка не вдається | Переконайтеся, що поточна папка містить `platformio.ini`, а потім повторіть обидві команди в кроці 2. |
| Екран залишається порожнім | Перевірте модель плати та назву середовища в журналі завантаження. Для дошки 1.75 рядок успіху повинен включати `stach-eyes-175`. |
| Телефон не може відкрити панель | Перевірте, чи все ще на `Stach-XXXXXX`, і відкрийте `http://192.168.4.1/`. Для першої реєстрації потрібен другий QR-код. |

Щоб переглянути діагностику, відкрийте послідовний монітор на швидкості 115200 бод.

```powershell
.\.venv\Scripts\python.exe -m platformio device monitor -p COM3 -b 115200
```

Надішліть `I` для звіту про ініціалізацію обладнання, `S` для списку пристроїв I²C або `D` для п’ятисекундної перевірки дисплея. Натисніть **Ctrl+C**, щоб закрити монітор.

Щоб відновити повну резервну копію на ту саму плату, закрийте монітор і спочатку перевірте розмір зображення. Наступна команда також відновлює налаштування та дані облікового запису, що містяться в резервній копії.

```powershell
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 write-flash 0x0 "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

## Історія та розвиток проекту

- **Етап 9 — Потужність.** Старіші профілі 1.43 вимірюють і фільтрують напругу АЦП на GPIO4. Оцінка заряду вимагає перевірки схеми для конкретної версії та калібрування за виміряною напругою акумулятора. Одне живлення USB не підтверджує зарядку. Профіль 1,75 зчитує AXP2101 безпосередньо.
- **Етап 10 — Режими та персоналізація.** Перемикайтеся між обличчям, Bluetooth-мишею, Wi-Fi QR і панеллю QR з дисплея або через `POST /api/mode`. Яскравість очей і активність погляду коливаються від 20% до 100%. Для керування мишею BLE потрібен апаратний профіль.
- **Етап 11 — Надійність і безпека.** Програмне забезпечення перевіряє походження запитів HTTP, захищає команди за допомогою маркера запиту, обмежує швидкість запитів і відновлює точку доступу Wi-Fi. Для профілю 1.75 також потрібен логін власника. [Етап 11 приміток безпеки](STAGE11-SECURITY.md)
- **Етап 12 — збірки та діагностика.** GitHub Actions перевіряє код і збирає пакети з контрольними сумами. `GET /api/hardware` повідомляє результати ініціалізації програмного забезпечення. Вихід дисплея, реакцію на дотик і сполучення можна перевірити на фізичній платі. [Зберіть і відпустіть](STAGE12-RELEASE.md) · [Апаратні тести](STAGE12-HARDWARE-TESTS.md) · [Апаратна діагностика](STAGE2-HARDWARE-DIAGNOSTICS.md)

Точкою входу мікропрограми є `src/main.cpp`. Заголовки знаходяться в `include/`, а джерело панелі керування - `web/stach-panel.html`. Після редагування панелі оновіть `preview/stach-panel.html` до відповідності, а потім запустіть `python tools/build_web_header.py`. Запустіть `python tools/check_panel.py`, щоб перевірити вбудовану сторінку та договір API (потрібен Node.js). У Linux запустіть `sh tools/test_core.sh` для тестів портативного ядра. Запустіть `python tools/test_ble_patch.py`, щоб перевірити сумісність патча BLE.

STACH — незалежний проект, натхненний жанром Pip-KeyPet. PlatformIO встановлює сторонні бібліотеки, а проект застосовує патч сумісності для ESP32 BLE Mouse 0.3.1. [Ресурси Waveshare 1.75](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75) · [Посилання на Waveshare 1.43](https://www.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.43)
