## একটি Waveshare 1.75 এ ইনস্টল করুন

এই নির্দেশাবলী `stach-eyes-175` PlatformIO পরিবেশের সাথে উইন্ডোজে পরীক্ষা করা হয়েছে। এটি রাউন্ড 466 × 466 CO5300 ডিসপ্লে, 16 MB ফ্ল্যাশ এবং 8 MB PSRAM এর জন্য `src/main.cpp` থেকে সম্পূর্ণ অ্যাপ্লিকেশন তৈরি করে। ফ্ল্যাশ করার আগে বোর্ডে মডেল বা এর প্যাকেজিং পরীক্ষা করুন। 1.43, 1.43B, এবং 1.75C সংশোধনগুলির বিভিন্ন হার্ডওয়্যার রয়েছে।

### 1. আপনার কম্পিউটার প্রস্তুত করুন

আপনার প্রয়োজন `py` লঞ্চার সহ Python 3.13, Windows এর জন্য Git, একটি USB ডাটা কেবল এবং প্রথম বিল্ডের জন্য একটি ইন্টারনেট সংযোগ। [উইন্ডোজের জন্য পাইথন](https://www.python.org/downloads/windows/) · [উইন্ডোজের জন্য গিট](https://git-scm.com/downloads/win)

PowerShell খুলুন এবং একটি নতুন ফোল্ডারে প্রকল্পটি ক্লোন করুন। ASCII অক্ষর সহ একটি সংক্ষিপ্ত পথ ESP32 সরঞ্জামগুলির সাথে ভাল কাজ করে।

```powershell
cd $env:USERPROFILE
git clone https://github.com/leonidgg2323-code/stach.git stach-firmware
cd stach-firmware
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "platformio==6.2.0"
```

বিকল্পভাবে, **কোড বেছে নিন → GitHub-এ ZIP** ডাউনলোড করুন এবং সংরক্ষণাগারটি বের করুন। `platformio.ini` ধারণকারী ফোল্ডারে PowerShell খুলুন এবং উপরের শেষ দুটি কমান্ড চালান। নীচের কমান্ডগুলি ভার্চুয়াল পরিবেশের পাইথনকে সরাসরি কল করে।

### 2. নির্ভরতা ইনস্টল করুন এবং তৈরি করুন

```powershell
.\.venv\Scripts\python.exe -m platformio pkg install -e stach-eyes-175
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175
```

প্রথম বিল্ডটি ESP32 টুলচেন ডাউনলোড করে এবং কয়েক মিনিট সময় নিতে পারে। বিল্ডটি স্বয়ংক্রিয়ভাবে ব্লুটুথ মাউস লাইব্রেরি সামঞ্জস্যপূর্ণ প্যাচ প্রয়োগ করে। আপলোড করার আগে `stach-eyes-175  SUCCESS` এর জন্য অপেক্ষা করুন।

### 3. সিরিয়াল পোর্ট খুঁজুন এবং বোর্ড ফ্ল্যাশ

USB দ্বারা বোর্ড সংযোগ করুন এবং উপলব্ধ পোর্ট তালিকা.

```powershell
.\.venv\Scripts\python.exe -m platformio device list
```

আপনি যখন বোর্ডটি প্লাগ ইন করেন তখন যে পোর্টটি প্রদর্শিত হয় এবং আপনি এটি আনপ্লাগ করার সময় অদৃশ্য হয়ে যায় তা সনাক্ত করুন। আপনার পোর্টের সাথে উদাহরণগুলিতে `COM3` প্রতিস্থাপন করুন। Arduino IDE সিরিয়াল মনিটর সহ এটি ব্যবহার করে যেকোনো প্রোগ্রাম বন্ধ করুন।

**আপলোডিং বোর্ডে ফার্মওয়্যার প্রতিস্থাপন করে।** ফ্যাক্টরি মেনু পুনরুদ্ধার করার বিকল্পটি রাখতে, আপলোড করার আগে সংগ্রহস্থলের বাইরে একটি সম্পূর্ণ ফ্ল্যাশ ব্যাকআপ সংরক্ষণ করুন৷ এই মডেলের জন্য একটি সম্পূর্ণ ব্যাকআপ হল **16,777,216 bytes** । আপনার যদি ইতিমধ্যে একটি ব্যাকআপ থাকে তবে একটি নতুন ফাইলের নাম ব্যবহার করুন৷ ছবিতে সেটিংস এবং শংসাপত্র থাকতে পারে, তাই এটি ব্যক্তিগত রাখুন৷

```powershell
.\.venv\Scripts\python.exe -m pip install "esptool>=5,<6"
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 read-flash 0 ALL "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

STACH ইনস্টল করতে, আপলোড কমান্ডটি চালান।

```powershell
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175 -t upload --upload-port COM3
```

চেকসাম চেক এবং `SUCCESS` বার্তার পরে বোর্ড পুনরায় চালু হয়। PlatformIO তাদের নিজ নিজ ঠিকানায় বুটলোডার, পার্টিশন টেবিল এবং অ্যাপ্লিকেশন লেখে। বিল্ড ডিরেক্টরির `firmware.bin` ফাইলটিতে শুধুমাত্র অ্যাপ্লিকেশন রয়েছে।

### 4. মালিকের অ্যাকাউন্ট নিবন্ধন করুন

1. প্রথম বুটে, আপনার ফোন দিয়ে **1/2 JOIN WI-FI** স্ক্যান করুন। `Stach-XXXXXX` নেটওয়ার্কে যোগ দিন। যদি আপনার ফোন রিপোর্ট করে যে এতে ইন্টারনেট অ্যাক্সেস নেই, **কানেক্টেড থাকুন** বেছে নিন।
2. ফোন সংযোগ করলে ডিসপ্লে **2/2 REGISTER** এ সুইচ করে। যদি প্রথম কোডটি এখনও প্রদর্শিত হয় তবে একবার প্রদর্শনটি আলতো চাপুন। একই ফোন দিয়ে দ্বিতীয় কোডটি স্ক্যান করুন।
3. 3-32টি অক্ষর (A–Z বা a–z), সংখ্যা, হাইফেন বা আন্ডারস্কোর এবং কমপক্ষে 12টি অক্ষরের একটি পাসওয়ার্ড বেছে নিন। আপনার লগইন বিবরণ সংরক্ষণ করুন. অ্যাকাউন্ট এবং সেটিংস বোর্ডে সংরক্ষণ করা হয়।
4. **Аккаунт владельца** (মালিকের অ্যাকাউন্টে), আপনি প্যানেলে দেখানো নাম পরিবর্তন করতে পারেন বা সাইন আউট করতে পারেন। পরে দেখার জন্য, বোর্ডের Wi-Fi-এ যোগ দিন এবং [স্থানীয় STACH কন্ট্রোল প্যানেল](http://192.168.4.1/) খুলুন।

বোর্ড একটি মালিকের অ্যাকাউন্ট গ্রহণ করে। রেজিস্ট্রেশনের জন্য ফিজিক্যাল ডিসপ্লেতে দেখানো এক-বারের কোড প্রয়োজন। কন্ট্রোল কমান্ডের জন্য একটি মালিক সেশন এবং একটি অনুরোধ টোকেন প্রয়োজন। প্যানেলটি বোর্ডের স্থানীয় Wi-Fi নেটওয়ার্কে HTTP ব্যবহার করে। বোর্ড পুনরায় চালু হওয়ার পরে আবার সাইন ইন করুন।

## প্রদর্শন এবং শক্তি

ফোনের প্যানেলে এক্সপ্রেশন নির্বাচন, একটি দৃষ্টি জয়স্টিক, ব্লিঙ্ক এবং টিল্ট কন্ট্রোল, চোখের উজ্জ্বলতা, এবং চোখ তাদের নিজের থেকে কতটা সরে যায় তার একটি সেটিং অন্তর্ভুক্ত করে। চেহারা সেটিংস রিস্টার্ট জুড়ে অব্যাহত থাকে। আপনি শুরু করার পরে মাউস মোড সক্ষম করতে পারেন।

1.75 বোর্ডে, **AXP2101** ব্যাটারি শতাংশ এবং চার্জিং অবস্থা রিপোর্ট করে। নির্দেশক `USB` দেখায় যখন বোর্ড তারের শক্তিতে চলে এবং ব্যাটারি শনাক্ত করে না। পাওয়ার সেভিং চালু থাকলে, 45 সেকেন্ড নিষ্ক্রিয়তার পর চোখের রিফ্রেশ রেট কমে যায় এবং 5 মিনিট পর স্ক্রীন বন্ধ হয়ে যায়। 15% বা তার কম চার্জে, সেই ব্যবধানগুলি 10 সেকেন্ড এবং 2 মিনিটে নেমে আসে। এটি জাগানোর জন্য স্ক্রীনটি স্পর্শ করুন। গেমস, QR কোড, মাউস মোড এবং সক্রিয় চার্জিং ডিসপ্লেকে জাগ্রত রাখে।

| বিল্ড ব্যর্থ হয় | আপনার বর্তমান ফোল্ডারে `platformio.ini` আছে কিনা পরীক্ষা করুন, তারপর ধাপ 2 এ উভয় কমান্ড পুনরাবৃত্তি করুন। |
| পর্দা ফাঁকা থাকে | আপলোড লগে বোর্ড মডেল এবং পরিবেশের নাম পরীক্ষা করুন। 1.75 বোর্ডের জন্য, সাফল্যের লাইনে `stach-eyes-175` অন্তর্ভুক্ত করা উচিত। |
| ফোন প্যানেল খুলতে পারে না | এটি এখনও `Stach-XXXXXX` -এ আছে কিনা পরীক্ষা করুন এবং `http://192.168.4.1/` খুলুন। প্রথমবার নিবন্ধনের জন্য দ্বিতীয় QR কোড প্রয়োজন৷ |

ডায়াগনস্টিক দেখতে, 115200 বউডে সিরিয়াল মনিটর খুলুন।

```powershell
.\.venv\Scripts\python.exe -m platformio device monitor -p COM3 -b 115200
```

হার্ডওয়্যার ইনিশিয়ালাইজেশন রিপোর্টের জন্য `I`, I²C ডিভাইসের তালিকা করতে `S`, অথবা পাঁচ-সেকেন্ডের ডিসপ্লে পরীক্ষার জন্য `D` পাঠান। মনিটর বন্ধ করতে **Ctrl+C** টিপুন।

একই বোর্ডে আপনার সম্পূর্ণ ব্যাকআপ পুনরুদ্ধার করতে, মনিটরটি বন্ধ করুন এবং প্রথমে চিত্রের আকার যাচাই করুন৷ নিম্নলিখিত কমান্ডটি ব্যাকআপে থাকা সেটিংস এবং অ্যাকাউন্ট ডেটা পুনরুদ্ধার করে।

```powershell
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 write-flash 0x0 "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

## প্রকল্পের ইতিহাস এবং উন্নয়ন

- **পর্যায় 9 — শক্তি।** পুরানো 1.43 প্রোফাইল GPIO4 এ ADC ভোল্টেজ পরিমাপ করে এবং ফিল্টার করে। আনুমানিক চার্জের জন্য নির্দিষ্ট সংশোধনের জন্য পরিকল্পিত পরীক্ষা করা এবং একটি পরিমাপিত ব্যাটারি ভোল্টেজের বিপরীতে ক্রমাঙ্কন করা প্রয়োজন। শুধুমাত্র ইউএসবি পাওয়ার চার্জিং নিশ্চিত করে না। 1.75 প্রোফাইল সরাসরি AXP2101 পড়ে।
- **পর্যায় 10 — মোড এবং ব্যক্তিগতকরণ।** ডিসপ্লে থেকে বা `POST /api/mode` এর মাধ্যমে মুখ, ব্লুটুথ মাউস, Wi-Fi QR এবং প্যানেল QR এর মধ্যে স্যুইচ করুন। চোখের উজ্জ্বলতা এবং দৃষ্টিশক্তি 20% থেকে 100% পর্যন্ত। BLE মাউস নিয়ন্ত্রণের জন্য একটি হার্ডওয়্যার প্রোফাইল প্রয়োজন।
- **পর্যায় 11 — নির্ভরযোগ্যতা এবং নিরাপত্তা।** ফার্মওয়্যার HTTP অনুরোধের উত্স পরীক্ষা করে, একটি অনুরোধ টোকেন সহ কমান্ডগুলিকে রক্ষা করে, অনুরোধগুলিকে হার-সীমাবদ্ধ করে এবং Wi-Fi অ্যাক্সেস পয়েন্ট পুনরুদ্ধার করে৷ 1.75 প্রোফাইলেরও মালিকের লগইন প্রয়োজন। [পর্যায় 11 নিরাপত্তা নোট](STAGE11-SECURITY.md)
- **পর্যায় 12 — বিল্ড এবং ডায়াগনস্টিকস।** GitHub অ্যাকশন কোড চেক করে এবং চেকসাম দিয়ে প্যাকেজ তৈরি করে। `GET /api/hardware` সফ্টওয়্যার প্রারম্ভিক ফলাফল রিপোর্ট. ডিসপ্লে আউটপুট, টাচ রেসপন্স এবং পেয়ারিং ফিজিক্যাল বোর্ডে পরীক্ষা করা যেতে পারে। [নির্মাণ এবং মুক্তি](STAGE12-RELEASE.md) · [হার্ডওয়্যার পরীক্ষা](STAGE12-HARDWARE-TESTS.md) · [হার্ডওয়্যার ডায়াগনস্টিকস](STAGE2-HARDWARE-DIAGNOSTICS.md)

ফার্মওয়্যার এন্ট্রি পয়েন্ট হল `src/main.cpp` । হেডারগুলি `include/` -এ থাকে এবং কন্ট্রোল প্যানেলের উৎস হল `web/stach-panel.html` ৷ প্যানেল সম্পাদনা করার পরে, ম্যাচ করার জন্য `preview/stach-panel.html` আপডেট করুন, তারপর `python tools/build_web_header.py` চালান। এম্বেড করা পৃষ্ঠা এবং API চুক্তি পরীক্ষা করতে `python tools/check_panel.py` চালান (Node.js প্রয়োজন)। লিনাক্সে, পোর্টেবল কোর পরীক্ষার জন্য `sh tools/test_core.sh` চালান। BLE প্যাচ সামঞ্জস্য পরীক্ষা করতে `python tools/test_ble_patch.py` চালান।
