STACH **Waveshare ESP32-S3-Touch-AMOLED-1.75** کو جیب کے ساتھی میں بدل دیتا ہے۔ اس کی آنکھیں آپ کی انگلی کی پیروی کرتی ہیں اور جھکاؤ کا جواب دیتی ہیں۔ گیم کھیلنے کے لیے دائیں سوائپ کریں، یا اپنے فون کا اظہار، چمک، برتاؤ، اور ڈسپلے کا نام تبدیل کرنے کے لیے استعمال کریں۔ بورڈ اپنے Wi-Fi نیٹ ورک اور کنٹرول پینل کی میزبانی کرتا ہے۔

## Waveshare 1.75 پر انسٹال کریں۔

ان ہدایات کا تجربہ ونڈوز پر `stach-eyes-175` PlatformIO ماحول کے ساتھ کیا گیا تھا۔ یہ راؤنڈ 466 × 466 CO5300 ڈسپلے، 16 MB فلیش، اور 8 MB PSRAM کے لیے `src/main.cpp` سے مکمل ایپلیکیشن بناتا ہے۔ چمکنے سے پہلے بورڈ یا اس کی پیکیجنگ پر موجود ماڈل کو چیک کریں۔ 1.43، 1.43B، اور 1.75C نظرثانی میں مختلف ہارڈ ویئر ہیں۔

### 1. اپنے کمپیوٹر کو تیار کریں۔

آپ کو `py` لانچر کے ساتھ Python 3.13، Git for Windows، USB ڈیٹا کیبل، اور پہلی تعمیر کے لیے انٹرنیٹ کنکشن کی ضرورت ہے۔ [ونڈوز کے لیے ازگر](https://www.python.org/downloads/windows/) · [ونڈوز کے لیے گٹ](https://git-scm.com/downloads/win)

پاور شیل کھولیں اور پروجیکٹ کو ایک نئے فولڈر میں کلون کریں۔ ASCII حروف کے ساتھ ایک مختصر راستہ ESP32 ٹولز کے ساتھ اچھی طرح کام کرتا ہے۔

```powershell
cd $env:USERPROFILE
git clone https://github.com/leonidgg2323-code/stach.git stach-firmware
cd stach-firmware
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "platformio==6.2.0"
```

متبادل طور پر، **کوڈ کا انتخاب کریں → GitHub پر ZIP** ڈاؤن لوڈ کریں اور آرکائیو کو نکالیں۔ `platformio.ini` والے فولڈر میں پاور شیل کھولیں اور اوپر دی گئی آخری دو کمانڈز چلائیں۔ نیچے دی گئی کمانڈز ورچوئل ماحول کے ازگر کو براہ راست کال کرتی ہیں۔

### 2. انحصار انسٹال کریں اور تعمیر کریں۔

```powershell
.\.venv\Scripts\python.exe -m platformio pkg install -e stach-eyes-175
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175
```

پہلی تعمیر ESP32 ٹول چین کو ڈاؤن لوڈ کرتی ہے اور اس میں کئی منٹ لگ سکتے ہیں۔ بلٹ بلوٹوتھ ماؤس لائبریری مطابقت کے پیچ کو خود بخود لاگو کرتا ہے۔ اپ لوڈ کرنے سے پہلے `stach-eyes-175  SUCCESS` کا انتظار کریں۔

### 3. سیریل پورٹ تلاش کریں اور بورڈ کو فلیش کریں۔

بورڈ کو USB کے ذریعے جوڑیں اور دستیاب پورٹس کی فہرست بنائیں۔

```powershell
.\.venv\Scripts\python.exe -m platformio device list
```

اس پورٹ کی شناخت کریں جو آپ کے بورڈ کو پلگ ان کرنے پر ظاہر ہوتا ہے اور جب آپ اسے ان پلگ کرتے ہیں تو غائب ہو جاتا ہے۔ اپنی پورٹ کے ساتھ مثالوں میں `COM3` کو تبدیل کریں۔ اس کا استعمال کرتے ہوئے کسی بھی پروگرام کو بند کریں، بشمول Arduino IDE سیریل مانیٹر۔

**اپ لوڈنگ بورڈ پر موجود فرم ویئر کی جگہ لے لیتی ہے۔** فیکٹری مینو کو بحال کرنے کے آپشن کو برقرار رکھنے کے لیے، اپ لوڈ کرنے سے پہلے ریپوزٹری کے باہر مکمل فلیش بیک اپ محفوظ کریں۔ اس ماڈل کا مکمل بیک اپ **16,777,216 bytes** ہے۔ اگر آپ کے پاس پہلے سے بیک اپ ہے تو ایک نیا فائل نام استعمال کریں۔ تصویر میں ترتیبات اور اسناد ہو سکتی ہیں، لہذا اسے نجی رکھیں۔

```powershell
.\.venv\Scripts\python.exe -m pip install "esptool>=5,<6"
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 read-flash 0 ALL "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

STACH انسٹال کرنے کے لیے، اپ لوڈ کمانڈ چلائیں۔

```powershell
.\.venv\Scripts\python.exe -m platformio run -e stach-eyes-175 -t upload --upload-port COM3
```

چیکسم چیک اور `SUCCESS` پیغام کے بعد بورڈ دوبارہ شروع ہوتا ہے۔ PlatformIO بوٹ لوڈر، پارٹیشن ٹیبل، اور ایپلیکیشن ان کے متعلقہ پتوں پر لکھتا ہے۔ بلڈ ڈائرکٹری میں `firmware.bin` فائل میں صرف ایپلی کیشن ہوتی ہے۔

### 4. مالک کا اکاؤنٹ رجسٹر کریں۔

1. پہلے بوٹ پر، اپنے فون سے **1/2 JOIN WI-FI** اسکین کریں۔ `Stach-XXXXXX` نیٹ ورک میں شامل ہوں۔ اگر آپ کے فون کی اطلاع ہے کہ اس میں انٹرنیٹ تک رسائی نہیں ہے، تو **منتخب کریں** جڑے رہیں۔
2. فون کے کنیکٹ ہونے پر ڈسپلے **2/2 REGISTER** میں بدل جاتا ہے۔ اگر پہلا کوڈ اب بھی دکھائی دے رہا ہے تو ایک بار ڈسپلے کو تھپتھپائیں۔ اسی فون سے دوسرا کوڈ اسکین کریں۔
3. 3–32 حروف (A–Z یا a–z)، ہندسوں، ہائفنز، یا انڈر سکورز، اور کم از کم 12 حروف کا پاس ورڈ منتخب کریں۔ اپنی لاگ ان کی تفصیلات محفوظ کریں۔ اکاؤنٹ اور سیٹنگز بورڈ پر محفوظ ہیں۔
4. **Аккаунт владельца** (مالک اکاؤنٹ) میں، آپ پینل میں دکھائے گئے نام کو تبدیل کر سکتے ہیں یا سائن آؤٹ کر سکتے ہیں۔ بعد کے دوروں کے لیے، بورڈ کے Wi-Fi میں شامل ہوں اور [مقامی STACH کنٹرول پینل](http://192.168.4.1/) کھولیں۔

بورڈ مالک کے ایک اکاؤنٹ کو قبول کرتا ہے۔ رجسٹریشن کے لیے فزیکل ڈسپلے پر دکھایا جانے والا ایک بار کا کوڈ درکار ہوتا ہے۔ کنٹرول کمانڈز کے لیے مالک کے سیشن اور درخواست کے ٹوکن کی ضرورت ہوتی ہے۔ پینل بورڈ کے مقامی Wi-Fi نیٹ ورک پر HTTP استعمال کرتا ہے۔ بورڈ دوبارہ شروع ہونے کے بعد دوبارہ سائن ان کریں۔

## ڈسپلے اور پاور

فون پینل میں ایکسپریشن سلیکشن، ایک گیز جوائس اسٹک، پلک جھپکنے اور جھکاؤ کے کنٹرول، آنکھوں کی چمک، اور یہ سیٹنگ شامل ہے کہ آنکھیں خود کتنی حرکت کرتی ہیں۔ ظاہری شکل کی ترتیبات دوبارہ شروع ہونے پر برقرار رہتی ہیں۔ آپ سٹارٹ اپ کے بعد ماؤس موڈ کو فعال کر سکتے ہیں۔

1.75 بورڈ پر، **AXP2101** بیٹری کی فیصد اور چارجنگ کی حیثیت کی اطلاع دیتا ہے۔ اشارے `USB` دکھاتا ہے جب بورڈ کیبل پاور پر چلتا ہے اور بیٹری کا پتہ نہیں لگاتا ہے۔ بجلی کی بچت کے فعال ہونے کے ساتھ، 45 سیکنڈ کی غیرفعالیت کے بعد آنکھوں کی تازگی کی شرح کم ہوجاتی ہے اور اسکرین 5 منٹ کے بعد بند ہوجاتی ہے۔ 15% یا اس سے کم چارج ہونے پر، وہ وقفے 10 سیکنڈ اور 2 منٹ تک گر جاتے ہیں۔ اسے جگانے کے لیے اسکرین کو ٹچ کریں۔ گیمز، QR کوڈز، ماؤس موڈ، اور فعال چارجنگ ڈسپلے کو بیدار رکھتی ہے۔

## خرابیوں کا سراغ لگانا اور بحالی

| علامت | کیا کوشش کرنا ہے |
|---|---|
| کوئی نیا COM پورٹ ظاہر نہیں ہوتا ہے۔ | ایک USB ڈیٹا کیبل اور دوسرا USB پورٹ آزمائیں، پھر `platformio device list` دوبارہ چلائیں۔ |
| پورٹ کو کھولا یا `Access denied` رپورٹ نہیں کیا جا سکتا | سیریل مانیٹر بند کریں۔ بورڈ کو دوبارہ جوڑیں اور اس کا COM نمبر چیک کریں۔ |
| تعمیر ناکام ہو جاتی ہے۔ | چیک کریں کہ آپ کے موجودہ فولڈر میں `platformio.ini` ہے، پھر مرحلہ 2 میں دونوں کمانڈز کو دہرائیں۔ |
| سکرین خالی رہتی ہے۔ | اپ لوڈ لاگ میں بورڈ ماڈل اور ماحول کا نام چیک کریں۔ 1.75 بورڈ کے لیے، کامیابی کی لکیر میں `stach-eyes-175` شامل ہونا چاہیے۔ |
| فون پینل نہیں کھول سکتا | چیک کریں کہ یہ ابھی بھی `Stach-XXXXXX` پر ہے اور `http://192.168.4.1/` کھولیں۔ پہلی بار رجسٹریشن کے لیے دوسرے QR کوڈ کی ضرورت ہوتی ہے۔ |

تشخیصات دیکھنے کے لیے، 115200 baud پر سیریل مانیٹر کھولیں۔

```powershell
.\.venv\Scripts\python.exe -m platformio device monitor -p COM3 -b 115200
```

`I` کو ہارڈ ویئر کی ابتدائی رپورٹ کے لیے، I²C آلات کی فہرست کے لیے `S` ، یا پانچ سیکنڈ کے ڈسپلے ٹیسٹ کے لیے `D` بھیجیں۔ مانیٹر کو بند کرنے کے لیے **Ctrl+C** دبائیں۔

اپنے مکمل بیک اپ کو اسی بورڈ پر بحال کرنے کے لیے، مانیٹر کو بند کریں اور پہلے تصویر کے سائز کی تصدیق کریں۔ درج ذیل کمانڈ بیک اپ میں موجود سیٹنگز اور اکاؤنٹ ڈیٹا کو بھی بحال کرتی ہے۔

```powershell
.\.venv\Scripts\python.exe -m esptool --chip esp32s3 --port COM3 write-flash 0x0 "$env:USERPROFILE\stach-before-install.flash-backup.bin"
```

## پروجیکٹ کی تاریخ اور ترقی

- **مرحلہ 9 — طاقت۔** پرانے 1.43 پروفائلز GPIO4 پر ADC وولٹیج کی پیمائش اور فلٹر کرتے ہیں۔ چارج کا تخمینہ لگانے کے لیے مخصوص نظرثانی کے لیے اسکیمیٹک کی جانچ پڑتال اور بیٹری وولٹیج کی پیمائش کے خلاف کیلیبریٹنگ کی ضرورت ہوتی ہے۔ صرف USB پاور چارجنگ کی تصدیق نہیں کرتی ہے۔ 1.75 پروفائل AXP2101 کو براہ راست پڑھتا ہے۔
- **اسٹیج 10 - موڈز اور پرسنلائزیشن۔** ڈسپلے سے یا `POST /api/mode` کے ذریعے چہرے، بلوٹوتھ ماؤس، Wi-Fi QR، اور پینل QR کے درمیان سوئچ کریں۔ آنکھوں کی چمک اور نگاہوں کی سرگرمی 20% سے 100% تک ہوتی ہے۔ BLE ماؤس کنٹرول کے لیے ہارڈویئر پروفائل کی ضرورت ہوتی ہے۔
